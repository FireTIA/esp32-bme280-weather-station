# ESP32 + BME280 | Автономная метеостанция вашей мечты 💫
Автономная метеостанция на ESP32 и BME280: веб-дашборд (Chart.js), WebSocket live-обновления, кольцевой буфер и Python-скрипт с автовосстановлением истории.

---

## ⚡ Функционал

### 🐍 Python логгер (Data Logger): 
1. **Логирование текущих значений:** Опрос ESP32 в реальном времени с настраиваемым интервалом.
2. **Автовосстановление истории (Backfill):** Если скрипт был выключен, при запуске он запрашивает кольцевой буфер ESP32, вычисляет точное время пропущенных измерений (даже при отсутствии NTP-синхронизации) и аккуратно дописывает историю без дубликатов.
3. **Запись в два формата:** Одновременная сохранность данных в удобный `.csv` (с разделителем `;`) и форматированный `.txt`.
4. **Цветная консоль:** Наглядный ANSI-вывод с визуальным разделением LIVE и HISTORY записей.
5. **Гибкая конфигурация (`settings.json`):** Настройка IP, портов, эндпоинтов, интервалов, путей к логам и параметров таймаутов/повторов.

### 🌐 ESP32 + BME280 (Прошивка & Web):
1. **Высокая точность:** Чтение температуры, влажности и атмосферного давления через I2C (BME280) с аппаратной фильтрацией шумов и авто-восстановлением при отвале датчика.
2. **WebSocket Live:** Мгновённая передача свежих данных (каждые 5 сек) на подключённые веб-клиенты без перезагрузки страницы.
3. **Кольцевой буфер истории:** Хранение до 2880 точек (48 часов измерений с шагом в 1 минуту) прямо в RAM ESP32.
4. **Умный REST API:** 
   - `/api/status` — текущее состояние датчика, Wi-Fi и аптайма.
   - `/api/history` — выдача истории с автоматическим прореживанием (даунсемплингом) для быстрой отрисовки графиков.
5. **Автономность & Captive Portal:** В случае потери Wi-Fi автоматически поднимается точка доступа AP (`192.168.4.1`) с перенаправлением трафика на дашборд и фоновыми попытками переподключения.
6. **Красивый Web-интерфейс:** Тёмная адаптивная тема, адаптивность под мобильные устройства и интерактивные графики Chart.js за 48 часов.
